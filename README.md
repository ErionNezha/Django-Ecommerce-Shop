# Django E-Commerce Shop

Dyqan online komplet në Django + React (Erion Nezha) — produkte, shportë, porosi, pagesa dhe panel admini.

`Python` `Django` `React`

## 🚀 Live Demo
Hape **`index.html`** në browser — demo-ja ekzekutohet direkt, pa instalime.
Nëse repo është publikuar me GitHub Pages: `https://erionnezha.github.io/Django-Ecommerce-Shop/`

## 📝 Kodi Burim
Kodi i plotë është në dosjen [`original/`](original/) dhe shfaqet krahas demo-s live në `index.html`.


> ⚠️ **Shënim sigurie:** `SECRET_KEY` origjinal i Django është zëvendësuar me placeholder — gjenero një çelës të ri për përdorim real.

## ▶️ Ekzekutimi origjinal
Backend: `python backend/manage.py runserver`. Frontend: `npm start` në dosjen frontend/.
